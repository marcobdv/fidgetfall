# Sample Clockwork — vision (toolchain demo)

> This is **not a real greenlit game** — it's the studio's "hello world" that
> proves the Godot 4 + C# + GdUnit4 toolchain works end to end. Use it as the
> template for a real `games/<slug>/` project.

- **Hook:** a tiny clockwork creature that runs and hops across a workbench.
- **Pillars:** *tactile movement* (game feel first), *legible placeholders*,
  *testable logic*.
- **Why it exists:** demonstrate the conventions in `docs/conventions.md` —
  exported tunables, pure-logic/`Node` separation, placeholder-first art, and
  headless tests — in the smallest project that still builds and runs.

When you greenlight a real concept, copy this structure, rename the assembly, and
replace this file with the actual vision (see the `game-design-doc` skill).
